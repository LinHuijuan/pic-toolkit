# 🖼️ 图片工具箱 PicToolkit

> 一款**纯前端、全功能**的本地图片处理工具，8 大能力开箱即用，所有图片**全程在本机（浏览器）处理**，永不上传服务器。

用 AI 辅助开发的作品 —— 从 0 到 1 用 AI 完成封面设计、SVG 图标、页面布局与代码实现，做出一款「真能打」的实用工具。

---

## ✨ 为什么值得一试

| 能力 | 说明 |
| --- | --- |
| 🔒 **隐私安全** | 图片不离开你的设备，全程本地处理，杜绝泄露风险 |
| 🤖 **真 AI** | AI 抠图、证件照换底色，在浏览器内跑 AI 模型（ONNX Runtime + WebGPU），无需上传 |
| ⚡ **即时反馈** | 一键「体验示例图」，空屏也能立刻感受完整处理链路；结果支持**前后拖动对比滑条** |
| 📱 **PWA 可安装** | 支持添加到主屏幕 / 桌面安装，可离线使用，体验接近原生 App |
| 🧩 **工具流转** | 一张图可依次在「编辑 → 抠图/切图/证件照 → 压缩/格式」间流转，形成完整流水线 |

## 🧰 功能一览

- **图片编辑** — 自由裁剪、旋转翻转
- **九宫格切图** — 朋友圈发图神器，支持留白与透明背景
- **添加水印** — 文字 / 图片水印，平铺、单点放置
- **AI 抠图** — 一键去背景，输出透明 PNG，可换背景色
- **图片压缩** — 本地压缩体积，按质量或目标体积，可批量
- **长图拼接** — 多图竖排 / 横排拼长图
- **证件照换底色** — AI 抠图一键换底，内置常见规格，支持一版多张打印
- **图片格式转换** — PNG / JPG / WebP 互转
- **网格拼图** — 多图拼网格，九宫格神器

## 🛠️ 技术栈

- **Vue 3**（组合式 API + TypeScript）
- **Vite 6** + **vite-plugin-pwa**（离线缓存 / 可安装）
- **@imgly/background-removal** — AI 抠图，浏览器内 ONNX Runtime + WebGPU
- GitHub Pages 子路径部署（`/pic-toolkit/`）

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 生产构建
npm run build

# 本地预览构建结果
npm run preview
```

## 🌐 部署

本仓库已配置 GitHub Actions（`.github/workflows/deploy.yml`），推送到 `main` 分支即可自动构建并部署到 GitHub Pages。

## 💡 设计理念

- **本地优先**：所有处理都在浏览器内完成，既是性能优势更是隐私承诺。
- **AI 落到实处**：不是"接入就完事"，而是让 AI 抠图与证件照真正可用且流畅（进度反馈、结果对比）。
- **体验至上**：空态可一键载入示例图、结果可拖动对比、前置进度提示，让工具「打开即懂、一玩就上头」。
